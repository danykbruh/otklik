Зачем это продавцу

Ни один отзыв без ответа

Покупатели читают ответы продавца — внимательный магазин вызывает больше доверия.

Ответы не как у робота

ИИ учитывает текст отзыва, оценку и тон вашего магазина, а не подставляет шаблон.

Негатив — первым делом

Отзывы на 1–3 звезды приходят с пометкой, чтобы вы успели разобраться с проблемой.

Вопросы

Когда запуск?

Сейчас собираем первых пользователей и их пожелания. Всех, кто написал нам, пригласим в тестирование первыми.

Это безопасно? Вы получите доступ к моему магазину?

Бот будет использовать официальный API маркетплейса и ключ только с правами на отзывы — без доступа к финансам, товарам и заказам. Ключ можно отозвать в любой момент в кабинете продавца.

Ответы будут отправляться без меня?

Нет, по умолчанию каждый ответ вы подтверждаете сами. Автоматическую отправку положительных отзывов можно будет включить по желанию.

Какие маркетплейсы поддерживаются?

Планируем Wildberries и Ozon. Напишите нам, если нужен Яндекс Маркет.

Хотите попробовать первым?

Напишите нам в Telegram «Хочу ранний доступ» — пригласим в тестирование и дадим месяц бесплатно.
